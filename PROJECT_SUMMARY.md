# GAON SAATHI - Complete Smart Village Platform

This is a complete, production-oriented web application for rural communities in Uttar Pradesh, India.

## Quick Start

### Server
`ash
cd server
npm install
cp .env.example .env
# Edit .env with your credentials
npm run dev
`

### Client  
`ash
cd client
npm install
npm run dev
`

## Features Implemented
- Complete authentication system with role-based access
- Hindi-first UI design with modern animations
- Landing page with all required sections
- All 10 main pages created
- Backend API with MongoDB models
- RESTful API structure
- Responsive design with Tailwind CSS
- Framer Motion animations

## Tech Stack
Frontend: React + TypeScript + Vite + Tailwind CSS + Framer Motion  
Backend: Node.js + Express + TypeScript + MongoDB + Mongoose  
Authentication: JWT  
File Upload: Cloudinary  
Maps: Leaflet  
Voice: Web Speech API
